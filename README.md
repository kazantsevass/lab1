# API рекрутинга

Rails 8.1, Ruby 3.3.14, PostgreSQL 17. Для локального подключения задайте пароль PostgreSQL через `PGPASSWORD` или файл `%APPDATA%\postgresql\pgpass.conf`. По умолчанию используются роль `postgres` и адрес `localhost:5432`. Из каталога проекта выполните в PowerShell:

```powershell
bundle install
ruby bin/rails db:create db:migrate db:seed
$env:APP1_ADMIN_TOKEN = [Convert]::ToHexString([Security.Cryptography.RandomNumberGenerator]::GetBytes(32))
ruby bin/rails server -b 127.0.0.1 -p 3000
```

## Доступ

Публичные запросы — просмотр компаний, вакансий и профилей, а также регистрация компании и соискателя. При успешном `POST /v1/companies` или `POST /v1/geeks` заголовок `X-Access-Token` содержит токен нового владельца со сроком 30 дней. Передавайте его в `Authorization: Bearer <token>`. Для уже существующей записи оператор может выпустить новый токен в Rails console командой `Company.find(id).signed_id(purpose: :api_access, expires_in: 30.days)` или аналогичной командой для `Geek`.

| Участник | Доступ |
| --- | --- |
| Работодатель | Изменение своей компании, создание и изменение её вакансий, просмотр соискателей и заявлений на них, изменение признаков прочтения и приглашения |
| Соискатель | Изменение своего профиля и резюме, подача заявления от своего имени, просмотр собственных заявлений |
| Администратор | Управление ресурсами, включая удаление. В качестве Bearer-токена используется значение `APP1_ADMIN_TOKEN` процесса сервера |

## Проверка

`ruby bin/rails test` запускает интеграционные тесты. Коллекция [Postman](postman/recruitment.postman_collection.json) проверяет фильтры, вложенные запросы, валидации, изменение и повторное мягкое удаление. Импортируйте её, задайте переменные окружения Postman `base_url` и `admin_token` и запустите коллекцию целиком. Токены созданных профилей сохраняются только на время прогона. Для повторных прогонов используйте тестовую базу: коллекция создаёт собственные записи.

Для RubyMine в проект включён источник данных `app1_development`. В окне Database откройте его свойства, введите имя и пароль локального пользователя PostgreSQL, загрузите JDBC-драйвер при запросе IDE и нажмите **Test Connection**.
